# Vishwashankar Janakiraman - Personal Portfolio

*A responsive 3D portfolio website showcasing my projects and experience.*

## 📖 About The Project

This repository contains the source code for my personal portfolio website. The site is designed to showcase my technical skills, past projects, and professional experience in an interactive and engaging way using 3D graphics and modern web technologies.

## 🛠 Built With

This project utilizes the following technologies:

* **[React.js](https://reactjs.org/)** - For the user interface.
* **[Three.js](https://threejs.org/)** - For the 3D graphics and interactive elements.
* **[Framer Motion](https://www.framer.com/motion/)** - For complex animations.
* **[Tailwind CSS](https://tailwindcss.com/)** - For styling and responsive design.

## ⚖️ Attribution

This portfolio was built using the [Portfolio-Template](https://github.com/shaqdeff/Portfolio-Template) created by **Shaquille Ndunda**. I have customized the content, assets, and specific components to reflect my own brand and work history, while retaining the core visual structure and 3D implementations provided by the original template.

## 🚀 Getting Started

If you wish to run a local copy of this project for development or testing purposes, follow these steps.

### Prerequisites

* Node.js (v16.0.0 or higher)
* npm (v9.0.0 or higher)

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/vishwashankartj/vishwashankartj.github.io.git
    ```

2.  **Navigate to the project directory**
    ```bash
    cd vishwashankartj.github.io
    ```

3.  **Install dependencies**
    ```bash
    npm install
    ```

4.  **Start the local development server**
    ```bash
    npm run dev
    ```

The application will be available at `http://localhost:5173/`.

## 📂 Project Structure

* `/src` - Contains the React components and logic.
* `/public` - Static assets (images, 3D models).
* `/assets` - Project-specific media files.

## 🚀 Deployment
This project can be easily deployed on platforms like [Netlify](https://www.netlify.com/) or [Vercel](https://vercel.com/).

### Environment Variables
For the contact form to work in production, you must configure the following environment variables in your deployment settings:

*   `VITE_APP_EMAILJS_SERVICE_ID`
*   `VITE_APP_EMAILJS_TEMPLATE_ID`
*   `VITE_APP_EMAILJS_PUBLIC_KEY`
*   `VITE_APP_EMAILJS_TO_EMAIL`
